# Summary preservation - guideline v1.0

Shown: a SUMMARY (method/model hidden) and one gold EXPERIENCE (+ CONDITION).

| judgment | meaning |
|---|---|
| faithful | expressed with its condition and a frequency wording consistent with the inputs |
| condition_lost | expressed but the condition is dropped or generalized |
| overstated | expressed with stronger scope/frequency than supported ("customers" for one report) |
| contradicted | the summary states the opposite |
| absent | not expressed |

Only `faithful` counts as preserved. A generic line ("some had issues") does not express a
specific experience.
